# Multilingual AI Voice Assistant

**Project by:** Hariteja Kodhaari  
**Institution:** VFSTR

### 1. Problem Statement
Many users are more comfortable communicating in their native languages than typing or interacting in English. Language barriers can make human-computer interaction difficult.

### 2. Proposed Solution
The Multilingual AI Voice Assistant enables users to communicate naturally through voice in Telugu, Hindi, and English. It recognizes spoken input, generates an intelligent response, and replies using synthesized speech.

### 3. Technology Stack
- Python and Streamlit – Application development and user interface.
- Gnani AI Prisma – Speech-to-Text.
- Groq LLM – Intelligent response generation.
- Gnani AI Timbre – Text-to-Speech.
- Python Requests and python-dotenv – API communication and configuration.

### 4. How It Works
1. The user selects a preferred language.
2. The user records a voice message.
3. Gnani AI Prisma converts speech into text.
4. Groq LLM generates an intelligent response.
5. Gnani AI Timbre converts the response into speech.
6. The application displays the response and provides audio playback.

### 5. Key Features
- Voice-based interaction.
- Telugu, Hindi, and English language support.
- Speech recognition and AI-generated responses.
- AI voice responses.
- Conversation history.
- Audio playback and download.

### 6. Expected Impact
The project aims to make AI interaction more accessible and convenient by supporting voice communication in multiple Indian languages.

### 7. Project Outcome
A multilingual voice assistant developed using Python, Streamlit, Gnani AI speech services, and Groq LLM.
